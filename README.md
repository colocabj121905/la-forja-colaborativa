# Archivo de la Casa Octocat

Proyecto para el Trabajo Práctico 8: Git, GitHub, Fork y Pull Request.

## Estructura

```text
index.html
css/style.css
img/
```

## Criterios para colaborar

1. Agregá tu nombre como un nuevo `<li>` dentro de `.participants`.
2. Agregá una tarjeta dentro de `.gallery`, usando exactamente la estructura del `<article class="card">` existente.
3. Guardá una imagen propia en `img/` y usá texto alternativo descriptivo.
4. Conservá las clases CSS y la paleta actual. No modifiques ni elimines tarjetas o nombres previos.
5. Hacé un commit descriptivo y explicá los archivos modificados en el Pull Request.
